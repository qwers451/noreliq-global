# noreliq-global — английская версия сайта

Международная версия сайта студии **Noreliq**: пять разделов, каждый — центрированный
плакат в своём цвете, и портфолио из четырёх кейсов с горизонтальной лентой работ.
Только английский, без российских реквизитов, телефона и цен. Собирается в статику и
раздаётся с GitHub Pages: [qwers451.github.io/noreliq-global](https://qwers451.github.io/noreliq-global/).

Русский сайт ([noreliq.ru](https://noreliq.ru)) живёт в репозитории `qwers451/noreliq`
и подключён сюда как remote `upstream`: исправления оттуда переносятся через `cherry-pick`.

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · [Lenis](https://github.com/darkroomengineering/lenis) для плавной прокрутки.

Анимационных библиотек нет: появление блоков и переходы сделаны на Web Animations API
и CSS-переходах, горизонтальные ленты — на нативной прокрутке.

## Команды

```bash
npm run dev     # дев-сервер на http://localhost:3000
npm run build   # продакшн-сборка
npm start       # запуск собранного приложения
npm run lint    # ESLint

GITHUB_PAGES=true npm run build   # статический экспорт в out/ — то, что уезжает на хостинг
```

## Страницы

| Маршрут | Что на ней |
|---|---|
| `/` | плакат с названием, две кнопки и строка «Selected work» с превью работ |
| `/about` | плакат о студии |
| `/services` | плакат + направления строками: индекс, описание, пакеты (без цен) |
| `/projects` | горизонтальная лента из четырёх работ с фильтрами по тегам |
| `/projects/[slug]` | кейс: мета с подписями, описание, листаемые кадры, ссылка на следующий проект |
| `/contacts` | плакат, почта и Telegram |

## Где править контент

Текста в JSX нет — всё лежит в `src/content/`:

| Файл | Что внутри |
|---|---|
| `site.ts` | название, слоган, почта, соцсети, SEO-дефолты |
| `nav.ts` | пункты меню — общий источник для шапки и мобильного меню |
| `services.ts` | направления работ и названия пакетов (цены на этой версии не публикуются) |
| `projects.ts` | кейсы: мета, теги, обложка-иконка, превью, блоки контента. Порядок в массиве = порядок в ленте |
| `about.ts` | сейчас используется только `lead` — текст на `/about` |
| `themes.ts` | цвет поля, текста, акцента и свечения для каждого раздела |

## Картинки

На статическом экспорте оптимизатора `next/image` нет, поэтому размеры нарезаются
заранее. Порядок при добавлении или замене снимка:

1. положить файл в `public/projects/<slug>/`;
2. прописать путь и исходные `width` / `height` в `projects.ts`;
3. **обязательно** прогнать нарезку:

```bash
node scripts/responsive-images.mjs
```

Скрипт кладёт рядом варианты на 480/960/1440 px и обновляет `src/content/image-widths.json`,
по которому `image-loader.ts` выбирает нужную ширину. Исходник не пережимается и остаётся
самым крупным вариантом. Без третьего шага телефон получит полноразмерный снимок.

Разовые скрипты подготовки кейсов (`prepare-*.mjs`, `*-cover.mjs`) лежат там же — они
переводят исходные PNG в WebP и собирают обложки.

Превью работ для ленты и главной (`preview.webp`, 16:10) собирает
`node scripts/project-previews.mjs`: общий светлый фон и экран продукта целиком.
После него тоже нужна нарезка `responsive-images.mjs`.

## Фирменный стиль

Цвета, шрифтовая шкала, тайминги и кривые — CSS-переменные в блоке `@theme`
файла `src/app/globals.css`: `--color-*`, `--text-hero/display/h2/h3/lead/body/label`
(все на `clamp()` и доступны как Tailwind-утилиты), `--dur-*`, `--ease-*`, `--gutter`, `--header-h`.
Ребрендинг = правка этого блока и `src/content/themes.ts`.

Шрифты подключены через `next/font` в `src/app/layout.tsx`: Manrope (заголовки и текст),
JetBrains Mono (служебные подписи), IBM Plex Mono (строки-комментарии `// …` и цифры).

## Движение

| Где | Что делает |
|---|---|
| `components/motion/SmoothScroll` | плавная прокрутка страницы (Lenis) |
| `components/motion/PageTransition` | прелоадер при первой загрузке и шторка при смене раздела |
| `components/motion/Reveal` | появление блоков при попадании в экран |
| `components/motion/Cursor` | кастомный курсор, только на десктопе с точным указателем |
| `components/motion/Grain` | шумовой оверлей |
| `lib/useCarousel.ts` | общая механика обеих горизонтальных лент: центрирование, доворот, перетаскивание, колесо, клавиши |

`lib/useReducedMotion.ts` — единый источник правды о том, можно ли анимировать.
Инлайн-скрипт в `layout.tsx` ставит на `<html>` класс `motion-ok`, и все «спрятанные до
анимации» состояния висят на нём. Поэтому при включённом «уменьшить движение» контент
виден сразу, прелоадера и шторки нет, Lenis и курсор не запускаются.

## Деплой

Пуш в `main` запускает `.github/workflows/deploy.yml`: сборка, экспорт и публикация на Pages.
Файла `public/CNAME` здесь нет специально: иначе репозиторий попытался бы занять домен
русского сайта. `public/.nojekyll` нужен, чтобы Pages не выкидывала папку `_next`.

| Переменная | Зачем |
|---|---|
| `GITHUB_PAGES=true` | включает `output: "export"` и `trailingSlash` |
| `NEXT_PUBLIC_SITE_URL` | адрес для `sitemap.xml`, canonical и OG |
| `NEXT_PUBLIC_BASE_PATH` | путь вида `/<repo>`; в workflow берётся из имени репозитория |

При непустом `NEXT_PUBLIC_BASE_PATH` сборка считается демо-стендом: префикс подставляется
в ссылки и картинки, а `robots.txt` закрывает её от индексации. Когда у версии появится
свой домен, нужно добавить `public/CNAME` и убрать базовый путь из workflow.

Локальная сборка с тем же путём (в Git Bash нужен `MSYS_NO_PATHCONV=1`, иначе путь
превращается в каталог Windows):

```bash
MSYS_NO_PATHCONV=1 GITHUB_PAGES=true NEXT_PUBLIC_BASE_PATH=/noreliq-global NEXT_PUBLIC_SITE_URL=https://qwers451.github.io/noreliq-global npm run build
```
